# תרגיל: Aggregation על ציונים 📊

בתרגיל הקודם עבדנו על **הזמנות** (Orders).
היום נעבוד על **ציונים של תלמידים** (Grades).
המבנה של הפרויקט **בדיוק אותו דבר**: model, controller, routes.

---

## שלב 0 – הכנת הפרויקט

1. מעתיקים את הפרויקט הקודם (`01-embebde-ref`) לתיקייה חדשה בשם `02-grades`.
2. מוחקים את התיקייה `dist`.
3. מריצים:
   ```
   npm install
   npm run dev
   ```
4. בודקים שמופיע: `MongoDB connected`.

## שלב 4 – Aggregation 🚀

לכל משימה: כותבים פונקציה ב-controller, מוסיפים route, ובודקים ב-Postman.
**התוצאה הנכונה כתובה למטה**, כדי שתוכלו לבדוק את עצמכם.

### תזכורת – מה עושה כל שלב

| שלב | מה הוא עושה | דוגמה מהתרגיל הקודם |
|---|---|---|
| `$match` | מסנן (כמו `find`) | הזמנות שהמחיר שלהן 150 ומעלה |
| `$group` | מקבץ לפי שדה ומחשב | הכנסות לפי מוצר |
| `$sort` | ממיין (`-1` מהגדול לקטן) | מוצרים מובילים |
| `$avg` / `$sum` | ממוצע / סכום (בתוך `$group`) | ממוצע הזמנה |

---

### משימה 1 – ממוצע כל הציונים
- **Route:** `GET /grades/average`
- **פונקציה:** `getAverageScore`
- **שלבים:** `$group` עם `_id: null` ו-`$avg`
- 💡 **רמז:** דומה ל-`getAverageOrderValue`

✅ **תוצאה נכונה:**
```json
{ "_id": null, "averageScore": 71 }
```

---

### משימה 2 – ממוצע לפי כיתה
- **Route:** `GET /grades/average-by-class`
- **פונקציה:** `getAverageByClass`
- **שלבים:** `$group` לפי `"$className"`. מחשבים ממוצע (`$avg`) וגם כמה ציונים יש בכל כיתה (`$sum: 1`)
- 💡 **רמז:** דומה ל-`getRevenueByProduct`

✅ **תוצאה נכונה** (הסדר יכול להיות שונה):
```json
[
  { "_id": "A", "averageScore": 68, "studentsCount": 5 },
  { "_id": "B", "averageScore": 74, "studentsCount": 5 }
]
```

---

### משימה 3 – מי עבר?
- **Route:** `GET /grades/passed`
- **פונקציה:** `getPassedGrades`
- **שלבים:** `$match`, ציון **60 ומעלה** (`$gte`)
- 💡 **רמז:** דומה ל-`getHighValueOrders`

✅ **תוצאה נכונה:** 7 ציונים (Dana, Yossi, Noa, Maya, Shira, Eitan, Lior)

---

### משימה 4 – המקצועות הכי טובים
- **Route:** `GET /grades/top-subjects`
- **פונקציה:** `getTopSubjects`
- **שלבים:**
  1. `$group` לפי `"$subject"` עם ממוצע ציונים
  2. `$sort` מהגבוה לנמוך
- 💡 **רמז:** דומה ל-`getTopProducts`

✅ **תוצאה נכונה** (בדיוק בסדר הזה):
```json
[
  { "_id": "Math",    "averageScore": 75 },
  { "_id": "History", "averageScore": 70 },
  { "_id": "English", "averageScore": 67.5 }
]
```

## ⭐ בונוס (למי שסיים)

### בונוס 1 – כמה נכשלו בכל כיתה?
- **Route:** `GET /grades/failed-by-class`
- **שלבים:** קודם `$match` (ציון **מתחת ל-60**, כלומר `$lt`), ואחר כך `$group` לפי כיתה עם `$sum: 1`

✅ **תוצאה נכונה:** כיתה A: 2, כיתה B: 1

### בונוס 2 – הציון הכי גבוה בכל מקצוע
- **Route:** `GET /grades/max-by-subject`
- **שלבים:** `$group` לפי מקצוע עם `$max: "$score"`

✅ **תוצאה נכונה:** Math: 100, English: 85, History: 95

---

## ⚠️ טעויות נפוצות
- שוכחים את ה-`$` לפני שם השדה: צריך `"$score"` ולא `"score"`.
- שוכחים לעשות `import` לפונקציה החדשה בקובץ ה-routes.
- ב-`$sort`: `-1` = מהגדול לקטן, `1` = מהקטן לגדול.
